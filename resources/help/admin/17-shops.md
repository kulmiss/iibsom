# Shops (business shop pages)

Phase 2: only shown when the **Business shop pages** switch is ON. Only the Super Admin can change shops.

Sellers make their shop at **Account → My shop**: name, web address (for example /shop/abdi-motors), logo, city, opening hours and a short text. The shop page shows all their live ads.

A shop is **public only while you turn it on**:

- **Waiting:** made by the seller, not turned on yet.
- **+1 month / +3 months / +12 months:** turns it on, or adds time to the end date. Do this after the seller paid you (outside the site for now).
- **Turn off:** the page disappears at once. The seller keeps their shop details.
- **Ended:** the time ran out. The page is hidden until you add time.

A banned seller's shop is hidden automatically.
