# Home page

**Home page** (menu: Website → Home page) lists every part of the home page, top to bottom, in the same order people see them.

- **Switch ON** = the part is shown. **Switch OFF** = it is hidden for everyone, on phones and computers, in English and Somali. Nothing is deleted: switch it on again any time.
- **Always shown** parts (the search box, the categories and the latest ads) have no switch: they are how people find ads.
- Some parts also need another feature. Then you see **"Not shown yet: also turn on …"**. For example, "Popular now" needs **Ad statistics**, and "Featured ads" needs **Paid boosts**.
- Some parts hide themselves when they have nothing to show, for example popular places with fewer than 2 places, or banners when none are added (add them in **Home banners**).
- A change shows on the site at once. It is written in the **Activity log**.

These are the same switches as in **Feature switches** (the ones that start with "Home:"); this page only shows them in page order.

Who can use it: staff who can change feature switches.
