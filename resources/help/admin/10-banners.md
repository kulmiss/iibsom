# Home banners

Pictures at the top of the home page.

- Best size: 1600 × 500 pixels.
- **Title:** also read out by screen readers, so describe the picture.
- **Link:** where a tap goes, for example /post or a full web address.
- **Show from / until:** the banner shows only between these dates.

Switch: **Home banners**.

## Paid banner ads (Phase 2)

When the **Banner ads** switch is ON, the form gets **Where it shows**:

- **Home slider:** as above (your own pictures).
- **Ad: home page / lists of ads / ad pages:** a paid banner for a business, with a small **Ad** label. Best sizes: 1200 × 300 (home and lists), 600 × 500 (ad pages).
- **Only in category / Only in city:** show it only there (a main category covers its sub categories). Empty = everywhere.
- **Advertiser:** the business name (for you; not shown).

Paid banners need a link. Each card shows **clicks** in the last 30 days and in all. Only the number is counted, never who clicked. When several banners fit one place, a random one shows.
