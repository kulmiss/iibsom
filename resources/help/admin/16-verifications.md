# ID checks (Verified badge)

Phase 2: only shown when the **Verified badge** switch is ON.

Sellers send a photo of their ID from **Account → Get the Verified badge**. A **Verified** badge then shows next to their name on their ads.

1. Open the photo (tap it to see it bigger).
2. Check that the name on the ID matches the name on the account, and that the photo is a real ID (not a screenshot or a drawing).
3. **Give Verified badge**, or **Not verified** with a short reason. The seller sees the reason and can send a new photo.

The ID photo is stored encrypted and **deleted as soon as you decide**. Every time someone opens a photo, it is saved in the **Activity log**.

To take a badge away later (for example after scam reports), open the user in **Users** and tap **Remove Verified badge**.

Moderators can do this too (permission "Check ID photos").
